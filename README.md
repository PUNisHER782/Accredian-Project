# Accredian Enterprise Landing Page

A Full Stack Developer Internship assignment built using **Next.js 15**, **TypeScript**, **Tailwind CSS**, and **GSAP**.

The objective of this project was to recreate the overall information architecture and user experience of the Accredian Enterprise landing page while implementing an original visual identity, reusable components, modern animations, and responsive design.

Reference Website:
https://enterprise.accredian.com/

---

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- GSAP
- Lucide React
- Next.js Route Handlers
- Vercel

---

## Features

- Fully responsive layout
- Sticky navigation with active section tracking
- Smooth scrolling using GSAP
- Hero section with staggered entrance animations
- Infinite logo carousel
- Animated statistics counter
- Feature and programme cards
- FAQ accordion
- Lead capture form with API route
- Accessible semantic HTML
- Reusable component architecture

## Installation

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Create a production build

```bash
npm run build
npm start
```

## My Approach

Before starting development, I analyzed the reference website to understand:

- Overall page structure
- User flow
- Component hierarchy
- Navigation behaviour
- Responsive layout
- Content grouping

Instead of creating a pixel-perfect copy, I recreated the same user journey while using my own visual styling, reusable components, and animations.
